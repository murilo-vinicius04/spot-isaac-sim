# spot-isaac-sim

Boston Dynamics Spot (with arm) in NVIDIA Isaac Sim. It started as a private copy of
[mschweig/IsaacRobotics](https://github.com/mschweig/IsaacRobotics) (Apache-2.0, kept as the `upstream` remote) and
adds two things:

- **`spot_isaac6/`**: Spot in **Isaac Sim 6.0** with the **spot_legcol60** walking policy. The policy was trained in
  Newton/MuJoCo with PufferLib (crawl-lab, `external/crawl-lab`) and ported to PhysX. It walks the same as in its
  Newton evaluation, scored by crawl-lab's own `eval.py` (0.5 m/s command, 10 s):

  | | Newton | PhysX |
  |---|---:|---:|
  | mean forward speed (m/s) | 0.468 | 0.468 |
  | speed error, rmse (m/s) | 0.038 | 0.037 |
  | base height (m) | 0.538 | 0.539 |
  | roll / pitch, 99th pct (deg) | 1.9 / 2.8 | 1.9 / 3.0 |
  | falls | 0 | 0 |

- **`applications/`**: the lab's teleop work on top of upstream. It holds Spot's cameras (`spot_cameras.py`), the
  ROS 2 bridge, the cuRobo arm subscriber, the phase-2 locomanipulation policy wrapper and the warehouse runner. These
  still use the Isaac 4.5/5.x APIs and the spot-teleop paths.

It is used as a submodule by `EESC-LabRoM/Spot_Chain` (branch `digital-twin`), which puts this Spot next to a
digital twin of a mooring chain.

## spot_isaac6

| Path | What it is |
|---|---|
| `legcol60.py` | The policy contract in code: observation layout, gait clock, 2-step action lag, arm offset fix, explicit PD with the knee torque envelope. numpy + onnxruntime only |
| `walk.py` | Runner: opens a stage, drives Spot from a per-physics-step callback, writes `trace.npz` (crawl-lab eval schema), `RESULT.json` and video frames |
| `make_spot_stage.py` | Adds Spot to a stage: `--open-floor`, or `--base your_scene.usda` to put it in your own scene |
| `assets/spot_legcol/` | The robot the policy trained on: crawl-lab's leg-collision Spot asset, generated by `external/crawl-lab/assets/make_selfcol_asset.py` |
| `policies/spot_legcol60/` | ONNX, `policy.yaml`, the training config, and `PORT_CONTRACT.md` (every convention, with file:line sources) |
| `stages/spot_floor.usda` | Open floor with 1 m stripes |
| `validation/` | The Newton reference trace, the PhysX open-floor runs (including A/B checks), `plot.py` and `ab_runs.sh` |

Details that matter when porting, all checked by A/B runs:
- **Arm input.** The arm observation is `q_arm - stow + carry`. The ONNX subtracts the wrong reference.
- **Last action.** `last_actions` lags two queries, not one.
- **Motors.** Torques are computed by the runner every 5 ms, with PhysX drive gains set to 0.
- **Joint friction** is set as absolute N·m through `physxJointAxis:angular:*FrictionEffort`.
- **Self-collision** is re-authored for PhysX, which collides everything unless filtered, the opposite of Newton.

### Running

```bash
git clone --recurse-submodules https://github.com/murilo-vinicius04/spot-isaac-sim.git && cd spot-isaac-sim
docker compose -f docker/compose.yaml up -d --build        # Isaac Sim 6.0.0 + onnxruntime; first build pulls ~20 GB
docker compose -f docker/compose.yaml exec isaac /isaac-sim/python.sh spot_isaac6/walk.py
python3 spot_isaac6/validation/plot.py out.png "PhysX=spot_isaac6/runs/spot_floor/trace.npz"   # score vs Newton
```

`external/crawl-lab` is a private fork (murilo-vinicius04/IsaacLab-Faster). It is needed only for `plot.py`'s
scoring, not for running the robot.

---

## Overview

This project provides example applications, pre-trained policies, and environment configurations for research and prototyping of autonomous quadruped and manipulator behaviors in complex environments such as warehouses.

The system leverages the power of Isaac Sim physics simulation and bridges it with ROS 2 for real-time testing and robotic development workflows.

---

## Features

* ✅ Isaac Sim simulation environments for Spot and Spot Arm
* ✅ RL policy controllers for locomotion
* ✅ Example applications including warehouse navigation
* ✅ ROS 2 bridge support for interfacing with external systems
* ✅ Modular and extensible structure for adding new robot models and policies

---

## Requirements

* NVIDIA Isaac Sim
* ROS 2 Humble
* rmw_zenoh
* GPU: NVIDIA RTX 40xx or better

---

## Installation

1. Clone the repository:

```bash
git clone https://github.com/mschweig/IsaacRobotics.git
```

2. Install Isaac Sim and required extensions (refer to Isaac Sim documentation).

3. (Optional) Install ROS 2 Humble and enable `isaacsim.ros2.bridge` extension in Isaac Sim.

---

## Usage

### Run Spot Arm in Warehouse Scenario

```bash
cd /workspaces/IsaacSim
./python.sh /workspaces/IsaacRobotics/applications/spot_warehouse.py
```

Control the robot via keyboard:

| Key               | Command       |
| ----------------- | ------------- |
| UP / NUMPAD\_8    | Move forward  |
| DOWN / NUMPAD\_2  | Move backward |
| LEFT / NUMPAD\_4  | Strafe left   |
| RIGHT / NUMPAD\_6 | Strafe right  |
| N / NUMPAD\_7     | Rotate left   |
| M / NUMPAD\_9     | Rotate right  |

### RL Policy Testing

The `applications/spot_policy.py` contains example implementations of PolicyControllers for Spot and Spot Arm.
You can adapt these for your custom simulation experiments.
